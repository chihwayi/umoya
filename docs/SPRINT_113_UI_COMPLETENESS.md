## Item 1 — VitalsPanel: Wire ML Deterioration + Show Interventions + Component Breakdown

### Background
- Backend has CDSS endpoint `/risk/deterioration/ml` that returns an ML-based deterioration probability.
- EarlyWarningService computes NEWS2 locally but never calls `/risk/deterioration/ml`.
- VitalsPanel shows `risk_level` badge and `recommendations` but never shows `interventions`.
- NEWS2 component breakdown (which parameters scored) is computed but not displayed.

### Backend Change — EarlyWarningService

File: `services/ehr-service/src/services/early-warning.service.ts`

Find the method that computes NEWS2 and stores the result. After computing the NEWS2 score, add:

```typescript

let deteriorationRisk: DeteriationRiskResult | null = null;
try {
  deteriorationRisk = await this.cdssService.callGovernedJson({
    surface: 'ml_deterioration',
    patientId: patient.id,
    task: 'predict_deterioration',
    payload: {
      news2_score: news2Score,
      news2_components: componentBreakdown,  // { rr, spo2, temp, sbp, hr, consciousness, supplemental_o2 }
      patient_age: patient.age,
      admission_hours: hoursAdmitted,

    outputSchema: {
      deterioration_probability: 'number',   // 0.0–1.0
      risk_horizon_hours: 'number',          // within how many hours
      contributing_factors: 'array',
      interventions: 'array',                // THESE must reach the UI
      confidence: 'number',
    },
  });
} catch {
  // Non-blocking — NEWS2 still works if ML model unavailable
  deteriorationRisk = null;
}

// Store combined result
await this.earlyWarningRepository.save({
  ...existingFields,
  news2Score,
  news2Components: componentBreakdown,       // Store the breakdown

export const recordFollowupOutcome = async (
  followupId: string,
  outcome: 'completed' | 'unable' | 'dismissed',
  notes?: string
): Promise<void> => {
  await fetch(`${API_BASE_URL}/patient-portal/followups/${followupId}/outcome`, {
    method: 'PATCH',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${getToken()}`,
      'X-Tenant-ID': getTenantId(),
    },
    body: JSON.stringify({ outcome, notes }),
  });
};
```

**Add to PatientPortalService** — updates `patient_followup_orchestrations.resolution_status` and writes a `cdss_feedback_entry` with the outcome:
```typescript
async recordFollowupOutcome(followupId: string, patientId: string, outcome: string, notes?: string) {
  const followup = await this.orchestrationRepo.findOneOrFail({ where: { id: followupId, patientId } });
  followup.resolutionStatus = outcome;
  followup.resolvedAt = new Date();
  await this.orchestrationRepo.save(followup);

  // Write outcome as feedback for self-learning
  if (followup.sessionId) {
    await this.cdssFeedbackService.recordPatientOutcome({
      tenantId: this.tenantId,
      logId: followup.sessionId,
      patientId,
      decisionType: 'patient_followup',
      outcomeAt30Days: { patient_reported_outcome: outcome, notes },
    });
  }
}
```
