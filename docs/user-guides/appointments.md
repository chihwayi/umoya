# Appointment Scheduling Guide

## Overview
The Appointment Scheduling module helps you manage patient appointments, view calendars, and handle waitlists.

## Features

### Creating Appointments
1. Navigate to **Appointments** → **New Appointment**
2. Select patient (search by name or ID)
3. Choose date and time
4. Select doctor/provider
5. Set appointment type (consultation, follow-up, procedure)
6. Add notes if needed
7. Click **Save**

### Calendar Views
- **Month View**: See all appointments for the month
- **Week View**: Detailed weekly schedule
- **Day View**: Hour-by-hour schedule for a specific day
- **Agenda View**: List of upcoming appointments

### Appointment Types
- **Consultation**: Regular doctor visit
- **Follow-up**: Post-treatment check-up
- **Procedure**: Medical procedure or surgery
- **Telehealth**: Virtual consultation
- **Emergency**: Urgent care visit

### Managing Appointments
- **Reschedule**: Change date/time
- **Cancel**: Cancel with reason
- **Complete**: Mark as completed
- **No-show**: Record missed appointment

### Recurring Appointments
- Set up recurring appointments for:
  - Weekly check-ups
  - Monthly follow-ups
  - Quarterly reviews
- Automatically creates future appointments

### Waitlist Management
- Add patients to waitlist when no slots available
- Automatic notification when slot opens
- Priority-based waitlist ordering

### Reminders
- SMS reminders (24 hours before)
- Email reminders
- In-app notifications
- Configurable reminder times

### Conflict Detection
- System automatically detects:
  - Double-booking
  - Overlapping appointments
  - Provider availability conflicts

## Best Practices
- Book appointments in advance
- Use appropriate appointment types
- Set realistic appointment durations
- Keep waitlist updated
- Send reminders to reduce no-shows
