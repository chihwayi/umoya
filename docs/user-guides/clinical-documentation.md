# Clinical Documentation Guide

## Overview
Clinical Documentation allows healthcare providers to record patient encounters, diagnoses, treatments, and care plans.

## Features

### Medical Records
- **Create Records**: Document patient encounters
- **Templates**: Use pre-built templates
- **SNOMED Coding**: Automatic diagnosis coding
- **Attachments**: Add documents, images, files
- **Timeline View**: Chronological record view

### Prescriptions
- **Create Prescriptions**: Prescribe medications
- **Drug Search**: Search drug database
- **Interaction Checking**: Check drug interactions
- **Dosage Calculator**: Calculate appropriate dosages
- **Templates**: Use prescription templates
- **ePrescription**: Generate digital prescriptions

### Lab Orders
- **Order Tests**: Request lab tests
- **Test Catalog**: Browse available tests
- **Order Sets**: Use pre-configured test sets
- **Results**: View and interpret results
- **Critical Alerts**: Get notified of critical values
- **Trends**: View result trends over time

### Vitals & Triage
- **Record Vitals**: Blood pressure, temperature, etc.
- **Triage Assessment**: Initial patient assessment
- **Nursing Notes**: Document nursing care
- **Alerts**: Abnormal vital alerts

### Clinical Templates
- **Note Templates**: Pre-built note templates
- **Custom Templates**: Create custom templates
- **Specialty Templates**: Specialty-specific templates
- **Quick Notes**: Fast documentation

### Specialty Modules
- **HIV Management**: Comprehensive HIV care
- **Diabetes Management**: Diabetes care plans
- **Oncology**: Cancer treatment tracking
- **Cardiology**: Heart condition management
- **Maternity**: Pregnancy and delivery tracking
- **Ophthalmology**: Eye care documentation

### CDSS Integration
- **Clinical Decision Support**: AI-powered insights
- **Drug Interactions**: Automatic checking
- **Diagnosis Suggestions**: Differential diagnosis
- **Treatment Recommendations**: Evidence-based guidance
- **Alerts**: Critical warnings

### Document Management (Sprint 19)
- **Upload Documents**: Drag-and-drop file upload for clinical documents
- **Document Types**: Lab results, imaging reports, consent forms, referrals
- **Version Control**: Track document versions and changes
- **Document Sharing**: Share documents with other providers
- **Search & Filter**: Find documents quickly by type, date, or tags
- **Access Control**: Role-based document permissions
- **Audit Trail**: Complete log of document access and changes
- **File Support**: PDF, DOC, DOCX, images, DICOM files

#### How to Use Document Management
1. **Upload Documents**:
   - Click "Documents" in the sidebar
   - Click "Upload" button
   - Drag and drop files or click to browse
   - Select document type (lab result, imaging, consent, etc.)
   - Add description and tags
   - Click "Upload All"

2. **View Documents**:
   - Browse document list with filters
   - Search by name, type, or tags
   - Click document to view details
   - Download or preview documents

3. **Version Management**:
   - Upload new version of existing document
   - View version history
   - Restore previous versions
   - Track changes with summaries

4. **Share Documents**:
   - Select document to share
   - Choose recipient (user or role)
   - Set permission level (view, download, edit)
   - Set expiration date (optional)
   - Recipients see shared documents in their inbox

5. **Organize Documents**:
   - Add tags for easy categorization
   - Filter by document type
   - Sort by date, name, or size
   - Archive old documents

### Provider Messaging (Sprint 20)
- **Secure Messaging**: HIPAA-compliant provider communication
- **Message Inbox**: Unified inbox for all provider messages
- **Message Types**: General messages, tasks, alerts, consultations, referrals
- **Priority Levels**: Urgent, high, normal, low priority settings
- **Message Threading**: Group related messages in conversations
- **Read Receipts**: Track message delivery and read status
- **Quick Actions**: Reply, forward, archive, delete messages
- **Search**: Find messages by subject, sender, or content
- **Templates**: Use pre-built message templates
- **Patient Context**: Link messages to specific patients/appointments
- **Task Assignment**: Create tasks from messages

#### How to Use Provider Messaging
1. **Send a Message**:
   - Click "Messages" in the sidebar
   - Click "Compose" button
   - Select recipient:
     - Individual user (specific doctor, nurse)
     - Role (all doctors, all nurses)
     - Team (ICU team, ER team)
   - Enter subject and message
   - Set priority (urgent/high/normal/low)
   - Select message type (message/task/alert/consultation)
   - Use template (optional)
   - Link to patient/appointment (optional)
   - Click "Send Message"

2. **Check Your Inbox**:
   - View unread count badge on Messages menu
   - Click "Messages" to open inbox
   - Browse three tabs:
     - Inbox: Received messages
     - Sent: Messages you sent
     - Archived: Archived messages
   - Click message to view details
   - Messages are auto-marked as read

3. **Reply and Forward**:
   - Open message from inbox
   - Click "Reply" to respond in thread
   - Click "Forward" to send to others
   - Add your message text
   - Click "Send"

4. **Use Message Templates**:
   - Click "Compose" button
   - Click "Use Template"
   - Select from categories:
     - Lab Results
     - Consultation
     - Referral
     - Follow-up
     - Urgent Alerts
     - General
   - Template auto-fills subject and message
   - Edit as needed
   - Send message

5. **Create Tasks from Messages**:
   - Open message with action needed
   - Click "Create Task" button
   - Enter task title and description
   - Assign to user
   - Set due date and priority
   - Click "Create Task"
   - Task appears in recipient's task list

6. **Search and Filter**:
   - Use search bar to find messages
   - Filter by:
     - Status (unread, read, archived)
     - Priority (urgent, high, normal, low)
     - Message type
   - Sort by date, sender, priority

7. **Message Actions**:
   - **Mark as Unread**: Flag for later review
   - **Archive**: Move to archived messages
   - **Delete**: Remove message (soft delete)
   - **View Read Receipts**: See who read the message

#### Message Best Practices
- Use appropriate priority levels
- Keep messages clear and concise
- Link messages to patients when relevant
- Use templates for common scenarios
- Respond promptly to urgent messages
- Archive completed conversations
- Create tasks for action items
- Use proper message types

## Best Practices
- Document immediately after patient encounter
- Use SNOMED CT codes for diagnoses
- Check drug interactions before prescribing
- Review critical alerts promptly
- Maintain accurate and complete records
- Use templates for efficiency
- Keep notes objective and factual
- Upload relevant documents to patient records
- Use provider messaging for care coordination
- Respond to urgent messages promptly
- Tag documents for easy retrieval
- Share documents securely within the platform
